# career-ops Gmail app

This is the home page of the "career-ops" Google OAuth app. It is a personal,
single-user app that lets [career-ops](https://github.com/career-ops-hq/career-ops),
running on the owner's own computer, read job-alert emails from one Gmail label.

- Access requested: `https://www.googleapis.com/auth/gmail.readonly` (read only).
- Users: the owner only. The app is not offered to anyone else.

See the [privacy policy](PRIVACY.md).
