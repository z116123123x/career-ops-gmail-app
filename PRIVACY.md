# Privacy policy: career-ops Gmail app

Last updated: 2026-11-24

**Who uses it.** This app is used only by its owner, on the owner's own
computer. It is not offered to other people.

**What it accesses.** With the owner's consent, the app uses the Gmail API with
the read-only scope `gmail.readonly`. It reads messages under one Gmail label
that the owner chooses, for a limited number of past days.

**What it does with the data.** It extracts job-posting links from those
messages and stores them in a local file on the owner's computer. It cannot
send, delete or change any email.

**Where data goes.** Gmail data is not sent to the app developer, sold, or
shared with third parties. The OAuth tokens stay in a local file on the
owner's computer. Job postings that the owner later chooses to evaluate may be
sent to the AI provider the owner uses for that evaluation.

**Use of Google user data.** The app's use of information received from Google
APIs adheres to the Google API Services User Data Policy, including the Limited
Use requirements.

**Revoking access.** Access can be revoked at any time at
https://myaccount.google.com/permissions.

**Contact.** Open an issue in this repository.
